# 🌍 EcoPulse

**EcoPulse** is a responsive climate-action web application designed to help people understand global warming and discover simple actions they can take to reduce their environmental impact.

The project was built using **HTML, CSS, and JavaScript**. For simplicity, all of the code is contained inside a single `index.html` file.

## 🌱 About the Project

Climate change is one of the major challenges facing the world today. EcoPulse makes information about climate action easier to understand and more interactive.

The website allows users to:

* Learn about some of the causes of global warming
* Explore energy, transport, food, and environmental impacts
* Estimate their personal carbon footprint
* Receive personalised climate-action suggestions
* Complete simple environmental challenges
* Track their progress
* Discover different climate tips
* Save their progress automatically in their browser

## 💻 Technologies Used

* **HTML5** — creates the structure and content of the website
* **CSS3** — controls the design, layout, animations, and mobile responsiveness
* **JavaScript** — powers the calculator, checklist, progress tracker, mobile menu, and climate tips
* **Local Storage** — remembers the user's calculator information and completed actions

## 📱 Responsive Design

EcoPulse is designed to work across different screen sizes, including:

* Desktop computers
* Laptops
* Tablets
* Mobile phones

## 🚀 Running the Website

No installation is required.

1. Download or clone the repository.
2. Open `index.html`.
3. The website will open in your web browser.

## 🌐 GitHub Pages

This project can also be hosted using GitHub Pages.

Go to:

**Settings → Pages → Deploy from a branch → main → /(root)**

Then save the settings.

## 🎯 Project Goal

The goal of EcoPulse is to show how web technology can be used to educate people about global warming while encouraging practical and achievable climate-friendly habits.

## ⚠️ Disclaimer

The carbon footprint calculator is a simplified educational feature created for this project. Its results should not be considered a professional or certified carbon assessment.
